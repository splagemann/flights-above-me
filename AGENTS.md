## Project

**flights-above-me** — shows aircraft overhead on a Leaflet map using browser geolocation and OpenSky data. Node/Express backend proxies flight and route APIs.

- `server.js` — Express backend (OpenSky + route proxy)
- `public/` — frontend (HTML/CSS/JS, Leaflet map)
- Deployed via Docker at `flights.basti.dev`
