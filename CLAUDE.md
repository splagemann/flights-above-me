# flights-above-me

Web app showing aircraft overhead using browser geolocation, Leaflet, and OpenSky data. Node/Express backend proxies OpenSky and route APIs.

## Dev

```bash
npm install && npm start  # http://localhost:3000
```

## Deploy

```bash
docker compose up -d --build
```
